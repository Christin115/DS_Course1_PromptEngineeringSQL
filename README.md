# Foundations of Prompt Engineering for SQL Workflows

Lab using the **Identify → Assemble → Execute → Verify** workflow to design and refine structured prompts (Task / Schema / Constraints / Output) that guide an AI assistant to generate SQLite queries for a healthcare operations scenario.

**Business question:** Which patients missed 2+ appointments (`no_show` or `canceled`) in the most recent 3-month reporting window?

## Files
- `PromptEngineeringSQL_Lab.ipynb`: the completed lab (Tasks 1–8): planning, initial and revised prompts, AI-generated SQL, review, validation and reflection
- `healthcare_operations_validation.ipynb`: provided validation notebook
- `healthcare_operations.db`: SQLite database (patients, appointments, providers, clinics, reporting_context)
